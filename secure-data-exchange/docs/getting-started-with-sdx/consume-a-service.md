---
title: Consume a Service 
---

Every consumer organization must complete onboarding before consuming a service through SDX. See [Onboarding Process](#onboarding-process) to get started. Once onboarding is complete, System Admins can begin consuming services through SDX.

The consumer journey includes:

1. Complete organization onboarding – see [Onboarding Process](#onboarding-process)
2. Register systems and subsystems – see [Managing Subsystems](#managing-subsystems)
3. Provision and configure an SDX Edge Runtime Group – see [Install an Edge Runtime Group](#install-an-edge-runtime-group)
4. Browse the service catalogue – see [Managing Services](#managing-services)
5. Request access to provider services – see [Connecting a Service](#connecting-a-service)
6. Establish secure connections and consume services – see [Connecting a Service](#connecting-a-service)

SDX applies consistent security, authentication, and governance controls to exchanges made through the platform.
