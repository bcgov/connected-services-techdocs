---
title: Consume a Service
---

Every consumer organization must complete onboarding before consuming a service through SDX. See [Onboarding Process Overview](onboarding-process/onboarding-process.md) to get started. Once onboarding is complete, System Admins can begin consuming services through SDX.

The consumer journey includes:

1. Complete organization onboarding – see [Onboarding Process](onboarding-process/onboarding-an-organization.md)
2. Register systems and subsystems – see [Managing Subsystems](onboarding-process/managing-subsystems.md)
3. Provision and configure an SDX Edge Runtime Group – see [Install an Edge Runtime Group](onboarding-process/install-an-edge-runtime-group.md)
4. Browse the service catalogue – see [Managing Services](onboarding-process/managing-services.md)
5. Request access to provider services – see [Connecting a Service](onboarding-process/connecting-a-service.md)
6. Establish secure connections and consume services – see [Connecting a Service](onboarding-process/connecting-a-service.md)

SDX applies consistent security, authentication, and governance controls to exchanges made through the platform.
