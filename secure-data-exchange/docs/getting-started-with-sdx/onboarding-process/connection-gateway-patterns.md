---
title: Connection Gateway Patterns
---

Connection gateway patterns define how secure connections between consumers and providers are configured in SDX. They provide a consistent way to apply the security and routing requirements needed for a specific connection.

This guide describes the configuration options available for both the consumer and provider sides of a peer-to-peer connection, including optional security capabilities such as signing, verification, token validation, access controls, and token exchange.

These patterns are configured as part of establishing and managing a connection in SDX, rather than being set up independently.

Technical guide: [Connection Gateway Patterns](https://developer.gov.bc.ca/docs/default/component/aps-infra-platform-docs/how-to/sdx-connection-patterns/)
