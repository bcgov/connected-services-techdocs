---
title: Onboarding an Organization 
---

This guide provides the technical instructions for setting up and managing an organization in P2P. It covers how to:

- Register an organization
- Assign System Admin access
- View organization information and access
- Assign an P2P gateway to an organization

These activities are performed by the P2P Operator, Organization Admin, and System Admin, depending on the task.

Technical guide: [Onboarding an Organization](https://developer.gov.bc.ca/docs/default/component/aps-infra-platform-docs/how-to/P2P-org-onboarding/)
